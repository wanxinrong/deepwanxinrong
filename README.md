# 怡口净水 · 江西定制助手

全屋净水方案报价工具（单文件网页，手机/电脑离线可用）。

## 功能
- 按江西 100 区县水质自动匹配方案
- 99 款机型库：搜索 / 分类筛选 / 参数卖点
- 默认五件套（前置+中央净水+中央软水+终端直饮+管线机）可增删
- 单价可改（改后标"已调价"，未改按牌价）、数量调整
- 多方案 A/B/C（最多 3 个）+ 对比图（差价徽标）
- 导出：报价单图片 / PDF / 纯文本 / PPT 方案书（每方案一页，含水路图）

## 本地使用
直接双击 index.html 用浏览器打开即可（无外部依赖）。

## 在线使用
开启 GitHub Pages 后访问仓库 Pages 地址。
